# Services V2 — lot de fondation du 26 octobre 2026

Base : `716812cd30939da569f04cb5e2d7c731a5fa1e55`.

Ce lot ajoute les services C# de configuration, intégrité, mise à jour,
exécution Windows et démonstration cohérente en mémoire, ainsi que leurs
contrats et contrôles ciblés. L’interface et le pont existants restent
ceux du lot précédent : les nouveaux services ne sont pas encore
raccordés à l’hôte dans ce commit. Le lot d’intégration suivant les relie.

Les protections couvrent les schémas fermés, sauvegardes préalables,
remplacements atomiques, plans et manifestes, opérations asynchrones,
annulation avec nettoyage, handles de fichiers et ruches privées.
Le moteur Windows n’a pas été exécuté. Les façades de tests ne
constituent pas une qualification Windows, USMT ou WebView2.

Écarts conservés : exécution V1 et magasins non compressés refusés ;
GitHub Releases public uniquement ; aucun pack PROD/DEV final ni Release.
Aucune modification de la V1, de ses packs ou de sa garde de publication.

Les suites natives `LoadedRegistryWindowsTests`, `ExecutionWindowsTests`
et `StorageFileIdentityWindowsTests` doivent rester exclues d’une preuve
Linux. Les résultats exacts et le rattachement au commit sont conservés
dans le reçu de publication des sources, séparément de cette note.
